# Fake News Detection System

A machine learning and NLP-based fake news detection system developed using Python.

## Features

* Text preprocessing and cleaning
* TF-IDF feature extraction
* Classification using Logistic Regression, SVM, and Naive Bayes
* Transformer-based classification using DistilBERT
* Model evaluation and visualization

## Technologies Used

* Python
* Scikit-learn
* PyTorch
* Transformers
* Pandas
* NumPy

## Objective

To compare classical ML models and transformer-based NLP models for fake news classification.
